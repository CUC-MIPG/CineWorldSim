# Tool Hub

This folder is reserved for future tool implementations and model assets.

- `models/`: local model files, checkpoints, weights
- `code/`: tool source code
- `configs/`: tool configs and env templates
- `assets/`: static resources used by tools
- `outputs/`: tool test outputs
- `logs/`: tool runtime logs

## Existing Tool Modules

- `code/post_production/`: standalone CLIs for post-production tool testing
  - `run_post_tools.py` (`audio` / `edit`)
