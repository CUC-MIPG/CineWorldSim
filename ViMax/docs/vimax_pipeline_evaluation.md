# ViMax Pipeline Output Evaluation

This is a standalone, offline evaluator for videos already generated by the current ViMax benchmark Pipeline. It does not start or modify generation. Results are custom experiments and are always marked `results_are_official_vimax_bench: false`.

## Run

Evaluate all cases and both tracks using the default ViCLIP HTTP service:

```bash
python scripts/run_vimax_pipeline_eval.py
```

Select one case and track, override the endpoint/settings, and choose a report path:

```bash
python scripts/run_vimax_pipeline_eval.py \
  --case chef_international_kitchens \
  --track A \
  --endpoint http://172.17.34.43:8890/embed \
  --num-frames 8 --resolution 224 --timeout 600 \
  --report outputs/vimax_benchmark/eval_chef_track_a.json
```

Use `--track-b-scene-diagnostics` to add separate diagnostic IC/CC metrics using generated Track B scene groups. These are never treated as source labels or mixed with protocol aggregates. `--smoke` selects a deterministic fake encoder to exercise discovery, report generation, and caching without calling ViCLIP; smoke scores are not reportable.

Additional options include repeatable `--case`, `--benchmark-root`, `--output-root`, `--cache-dir`, and `--report`. The default cache is stored under the output root. Incomplete samples are recorded but not scored; when all selected samples are incomplete the report is still written and the command exits with status 2. Decode, service, and embedding-validation failures include case/shot context and fail the command.

## Evaluation Protocol

Track A clips are discovered at `track_A/vimax_pipeline/shots/<idx>/video.mp4`. Source labels are assigned in sorted `(scene_num, shot_id)` order only when clip indices are contiguous from zero and the count matches exactly. Otherwise, the record is incomplete and has no metrics.

Track B clips are discovered at `track_B/vimax_pipeline/scene_<n>/shots/<idx>/video.mp4`. `script.json` and each scene `storyboard.json` define expected output inventory only. Track B primary results include GC, without source-scene labels. The optional generated-scene diagnostics remain in their own report section.

The default encoder is the ViCLIP `/embed` endpoint at `http://172.17.34.43:8890/embed`, with 8 sampled frames, resolution 224, a 600-second timeout, and expected 768-D normalized embeddings. Cache entries are keyed by resolved path, file size, modification time, endpoint, frame count, and resolution.

The JSON report and terminal output show one concise row per case and track with only the final IC, CC, and GC scores. Track B IC/CC are `null`/`N/A` because source scene labels are unavailable; no combined score is invented. Incomplete cases show status and a short diagnostic instead of scores. This implementation is not an official ViMax-Bench result adapter.
